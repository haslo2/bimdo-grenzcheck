01 — Funktionen

Alles was Sie für eine saubere Grenzabstandsprüfung brauchen.

Sechs zentrale Bausteine — von der Parzellenabfrage bis zum anschaulichen PDF-Bericht. Direkt in Blender, ohne Wechsel des Tools.

F.01

Parzellen-Workflow

EGRID eingeben, Parzelle abfragen, GPKG laden. Boundary Check übernimmt die Geometrie verlustfrei und richtig georeferenziert.

Input · EGRID / GPKG
F.02

Grenzabstand-Check

Misst jeden Punkt des Gebäudes gegen jede Parzellengrenze. Konflikte werden grün, gelb oder rot kategorisiert.

Core · Engine
F.03

Swiss Context

Nachbarparzellen, Höhenmodell und Gebäudegrundrisse via swisstopo-API direkt in die Szene laden.

Data · swisstopo
F.04

IFC-Import

Bringt das Bauprojekt via IfcOpenShell als BIM-Modell in Blender. Geschosse, Räume und Achsen bleiben erhalten.

BIM · IfcOpenShell
F.05

Docker-Pipeline

GDAL, Conversion-Skripte und Geodatenverarbeitung in einem reproduzierbaren Container — kein lokales Setup nötig.

DevOps · Container
F.06

PDF-Bericht

Vier Ansichten, farbcodierte Tabelle, EGRID-Referenzen und Behördensiegel — ein Klick zum anschaulichen Prüfdokument.

Output · A4 / A3
Tech Stack

02 — Workflow

Vom EGRID bis zum PDF — in acht Schritten.

Ein linearer, nachvollziehbarer Ablauf. Jeder Schritt ist innerhalb von Blender erreichbar, ohne externe Programme zu wechseln.

01

EGRID eingeben

Eidg. Grundstücksidentifikator als Eingabe — z. B. CH881234567012. Boundary Check übernimmt den Rest.

02

Parzelle abfragen

Geometrie, Eigentümer und Nachbarn werden über die OEREB-Schnittstelle bezogen und gecacht.

03

GPKG erzeugen

Docker-Pipeline konvertiert die Rohdaten via GDAL in ein verlustfreies GeoPackage in LV95.

04

In Blender importieren

Parzelle, Nachbargrenzen und Geländemodell werden georeferenziert in die Szene gelegt.

05

IFC-Modell laden

Das Bauprojekt wird via IfcOpenShell in die Szene importiert und auf die Parzelle ausgerichtet.

06

Grenzabstand prüfen

Der Solver misst minimale Distanzen pro Grenze und kategorisiert sie nach kantonalen Sollwerten.

07

Visualisierung

Konfliktbereiche werden in 3D markiert, vier Standardansichten werden automatisch gesetzt.

08

PDF exportieren

Bericht mit Tabelle, Ansichten und Behördenkopf wird als .pdf generiert und abgespeichert.
